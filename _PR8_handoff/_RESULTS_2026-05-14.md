## 적용한 fix 2개

### Fix 1: `compute_backtracking_signature`를 fail-aware로
**위치**: `src/signature/ref/lvlx/sign.c:97-130` (함수) + `:559-564` (caller)
**변경**:
- `void` → `int` (1=success, 0=retry signal)
- `quat_alg_make_primitive` 호출 후 release-build에서 살아있는 `quat_lattice_contains` 호출로 invariant 명시 검사
- caller `protocols_sign`에서 `if (!compute_backtracking_signature(...)) { ret=0; continue; }`

**효과**: 첫 종류의 silent invariant 위반 (`make_primitive`의 ok=0)이 outer retry 보내짐. retry 메커니즘 일부 살아남.

### Fix 2: `compute_random_aux_norm_and_helpers`를 fail-aware로
**위치**: `src/signature/ref/lvlx/sign.c:132-212` (함수) + `:570-583` (caller)
**변경**:
- 시그니처 변경: `uint_fast8_t fn(...)` → `int fn(uint_fast8_t *out_pow_dim2_deg_resp, ...)` (out 인자 + success/fail)
- 두 invariant (`norm_d != 1`, `remain != 0`) 위반 시 `goto done` + `return 0`
- caller에서 `if (!...) { ret=0; continue; }`

**효과**: 두 번째 종류 silent invariant 위반(`quat_alg_norm` 결과)도 retry로 처리. 하지만 같은 sk에서 매번 같은 invariant 위반 → outer retry 무한 → 결국 timeout.
